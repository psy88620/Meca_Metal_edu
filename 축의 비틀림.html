축의 비틀림

만든이 : 기계금속 교사 박승엽

회전하는 축은 토크를 전달하면서 조금씩 비틀려요. 토크, 지름, 길이를 바꿔 보면서 비틀림각과 전단응력이 어떻게 달라지는지 확인해 보세요. 실제 비틀림은 아주 작아서 화면에서는 크게 확대해서 보여 줘요.

한쪽을 고정한 축에 토크 걸기

왼쪽 벽에 고정, 오른쪽 끝에 토크 T. 표면의 선이 비틀리는 정도를 보세요.

-

조건 바꾸기

계산 결과

지름에 따른 비틀림각

지름이 조금만 커져도 비틀림이 확 줄어요(d⁴에 반비례). 점이 지금 상태예요.

공식

J = π d⁴ / 32
τ = T·r / J = 16T / π d³
θ = T·L / (G·J)
P = T·ω
  • 전단응력은 중심에서 0이고 표면에서 최대예요. 그래서 축은 표면부터 파손돼요.
  • 지름이 2배면 응력은 1/8, 비틀림각은 1/16이 돼요.
  • 길이가 길수록, 재료가 물렁할수록(G가 작을수록) 더 많이 비틀려요.
  • 같은 출력이라면 회전수가 높을수록 토크는 작아져요(T = P/ω).

그래서 현장에서는

  • 선반 스핀들과 구동축은 큰 토크를 전달해서 비틀림 강성이 중요해요. 속이 빈 중공축은 같은 무게에서 비틀림에 더 강해요.
  • 드릴이 길고 가늘수록 비틀림 때문에 끝이 쉽게 부러져요. d가 작으면 응력이 d³에, 각도가 d⁴에 반비례해서 급격히 나빠져요.
  • 모터 용량(kW)과 회전수가 정해지면 축이 받는 토크가 정해지고, 거기에 맞게 축 지름을 골라요.

생각해 보기

축 지름을 2배로 키우면 최대 전단응력은 몇 배가 될까요?
τ = 16T/πd³ 이므로 (1/2)³ = 1/8배예요.
축의 길이를 2배로 하면 비틀림각은?
θ = TL/GJ 에서 L에 비례하므로 2배예요. 응력은 길이와 상관없이 그대로예요.
7.5 kW 모터가 1500 rpm으로 돌릴 때 축의 토크는?
ω = 2π × 1500 / 60 = 157 rad/s, T = 7500 / 157 ≈ 47.7 N·m 예요.
