습공기선도는 이렇게 생겼습니다

공기 속에는 눈에 보이지 않는 수증기가 약 1% 들어 있습니다. 수증기를 포함한 공기를 습공기, 수증기가 전혀 없는 공기를 건공기, 더 이상 수증기를 품을 수 없는 상태를 포화공기라고 합니다.

습공기선도는 가로축에 건구온도, 오른쪽 세로축에 절대습도를 잡고, 표준대기압(101.325 kPa)에서 포화공기선을 그린 뒤 여러 상태량의 선을 겹쳐 그린 그림입니다. 두 가지 값만 알면 상태점이 하나로 정해지고, 나머지 값은 모두 선도에서 읽을 수 있습니다. 포화공기선보다 위쪽은 안개가 낀 과포화(무입공기) 상태입니다.

각 선을 읽는 방법

건구온도 t
상태점에서 수직으로 내려 하단 눈금을 읽습니다.
습구온도 t′
상태점에서 왼쪽 위로 기울어진 점선(습구온도선)을 따라 포화공기선과 만나는 점의 온도입니다.
노점온도 t″
절대습도를 그대로 두고 왼쪽으로 수평 이동해 포화공기선과 만나는 점의 온도입니다. 공기를 이 온도 아래로 식히면 이슬이 맺힙니다.
절대습도 x
상태점에서 오른쪽으로 수평 이동해 우측 눈금을 읽습니다. 건공기 1 kg에 들어 있는 수증기 질량 [kg/kg′].
상대습도 φ
오른쪽 위로 휘어진 곡선. 같은 온도의 포화 수증기압에 대한 현재 수증기 분압의 비 φ = pv/ps.
엔탈피 h
왼쪽 위로 기울어진 실선을 따라 포화선 바깥의 엔탈피 눈금을 읽습니다. 현열과 잠열을 합한 전열량 [kJ/kg′].
비체적 v
급경사로 그어진 선. 건공기 1 kg을 포함한 습공기의 부피 [m³/kg′].
포화도 ψ
같은 온도의 포화 절대습도에 대한 비 x/xs. 선도에 선은 없고 계산으로 구합니다.

수행 순서 (교재 예제)

  1. 건구온도 32℃와 상대습도 55%가 만나는 상태점을 표시한다.
  2. 절대습도가 일정하게 포화공기선과 만나는 노점온도 21.83℃를 읽는다.
  3. 습구온도선을 따라 포화공기선과 만나는 습구온도 24.62℃를 읽는다.
  4. 우측의 절대습도 x = 0.0165 kg/kg′를 읽는다.
  5. 엔탈피 h = 74.42 kJ/kg를 읽는다.
  6. 비체적 v를 읽는다. 교재에는 0.813 m³/kg으로 적혀 있지만, 32℃ 건공기만으로도 0.287 × 305.15 / 101.325 = 0.864 m³/kg이므로 이 상태의 바른 값은 약 0.887 m³/kg입니다(교재 오기로 보입니다).

위의 교재 예제 불러오기 → 건구 32℃ · φ 55%를 누르면 선도 위에 읽는 선이 모두 그려집니다. 손으로 읽은 값과 비교해 보세요.

공조 프로세스 계산식

풍량 Q [m³/h], 공기 밀도 ρ = 1.2 kg/m³일 때 공기 질량유량 G = ρQ [kg/h].

가열(현열) qS = G(h₂ − h₁) 가습량 L = G(x₃ − x₂) 냉각열량 qC = G(h₁ − h₂), 감습량 L = G(x₁ − x₂) 혼합: t₃ = t₁ + (t₂ − t₁)k, h₃ = h₁ + (h₂ − h₁)k, x₃ = x₁ + (x₂ − x₁)k 현열비 SHF = qS / (qS + qL), 열수분비 u = Δh / Δx

혼합점 ③은 항상 ①과 ②를 잇는 직선 위에 있고, 혼합 비율 k만큼 ② 쪽으로 이동한 곳입니다. 냉각 코일 표면이 노점온도보다 낮으면 노점에 닿은 뒤부터 냉각과 함께 감습이 일어납니다.

이 페이지가 쓰는 계산식

ps : Hyland–Wexler 식 (ASHRAE, 0℃ 미만은 얼음 기준) x = 0.622 · pv / (P − pv) h = 1.006 t + x (2501 + 1.86 t) [kJ/kg′] v = 0.287 (t + 273.15)(1 + 1.6078 x) / P [m³/kg′] x = [(2501 − 2.326 t′) xs′ − 1.006 (t − t′)] / (2501 + 1.86 t − 4.186 t′)

대기압을 바꾸면(고지대 등) 포화공기선과 모든 값이 다시 계산됩니다.

P-h 선도(몰리에르 선도)의 구성

세로축에 절대압력 P(로그 눈금), 가로축에 비엔탈피 h를 잡은 선도입니다. 일정 압력 변화와 교축 작용이 직선으로 나타나 엔탈피 차, 즉 열량을 바로 읽을 수 있습니다. 압력은 절대압력이므로 게이지 압력과 비교할 때 대기압(약 101 kPa)을 더해야 합니다.

포화액선
왼쪽 아래에서 위로 올라가는 굵은 곡선. 왼쪽은 과냉각액, 선 위는 포화액(건조도 0).
포화증기선
오른쪽 굵은 곡선. 선 위는 건조포화증기(건조도 1), 오른쪽은 과열증기.
등압선
수평선. 증발·응축 과정은 이 선을 따라 일어납니다.
등엔탈피선
수직선. 팽창밸브의 교축 과정(h₃ = h₄)이 이 선을 따릅니다.
등온선
과냉각액 구역에서는 거의 수직, 습증기 구역에서는 등압선과 겹쳐 수평, 과열 구역에서는 아래로 휘어집니다. 온도 눈금은 포화선 위에 적습니다.
등엔트로피선
과열 구역에서 오른쪽 위로 비스듬히 올라가는 선. 단열 압축(1→2)이 이 선을 따릅니다.
등비체적선
점선. 냉매 1 kg의 부피가 같은 점을 이은 선. 흡입증기 비체적 v₁로 피스톤 압출량을 구합니다.
등건조도선
습증기 구역 안의 점선. 증기의 질량 비율 x (포화액 0, 포화증기 1).

표준 냉동사이클 4과정

1 → 2 압축
등엔트로피 단열 압축. 압축일 Aw = h₂ − h₁
2 → 3 응축
등압 방열. 과열 제거 → 응축 → 과냉각. qc = h₂ − h₃
3 → 4 팽창
등엔탈피 교축. h₃ = h₄, 포화액 일부가 증발해 습증기가 됩니다.
4 → 1 증발
등압 흡열. 냉동효과 qe = h₁ − h₄

에너지 보존: qc = qe + Aw. 흡입증기가 포화증기선 오른쪽이면 과열압축, 선 위면 건조포화압축, 왼쪽이면 습압축입니다. 습압축은 액압축(리퀴드 백) 위험이 있어 보통 약간 과열시켜 흡입합니다.

냉동능력·동력·성적계수

냉매 순환량 G = Qe / qe [kg/h] 실제 흡입 가스량 V = G · v₁ [m³/h], 피스톤 압출량 Vth = V / ηv 이론 동력 Nth = G · Aw / 3600 [kW] 축동력 N = Nth / (ηc · ηm) 이론 COP = qe / Aw = (h₁ − h₄) / (h₂ − h₁) 실제 COP = 이론 COP × ηc × ηm 카르노 COP = Te / (Tc − Te) (절대온도) 1 RT(냉동톤) = 13,911 kJ/h ≈ 3.86 kW

실제 압축은 단열효율 ηc 때문에 토출 엔탈피가 h₂′ = h₁ + (h₂ − h₁)/ηc로 커지고, 토출온도도 올라갑니다. 선도에서 2′ 점으로 표시합니다. COP는 압축기가 얼마나 좋은 효율로 열을 옮기는지 나타내며 클수록 좋습니다.

조건을 바꾸며 관찰할 것

  • 증발온도를 낮추면 흡입압력이 떨어지고 v₁이 커져 냉매 순환량이 줄고, 압축비와 압축일이 커져 COP가 떨어집니다.
  • 응축온도를 높이면 플래시가스가 늘어(점 4의 건조도 증가) 냉동효과가 줄고 동력이 늘어납니다.
  • 과냉각도를 늘리면 h₃가 작아져 냉동효과가 커집니다.
  • 과열도를 늘리면 토출온도가 올라갑니다. 암모니아는 토출온도가 특히 높습니다.
  • 교재 예제와 값이 조금 다를 수 있습니다. 이 선도는 CoolProp 물성식으로 그렸고 엔탈피 기준점(R-717: −40℃ 포화액 0 kJ/kg, 할로카본: 0℃ 포화액 200 kJ/kg)이 교재 선도와 달라 h 값 자체는 수십 kJ/kg 차이가 날 수 있지만, 엔탈피 차(qe, Aw, COP)는 거의 같습니다.
  • 실제 장치는 배관 마찰로 압력강하가 있어 증발·응축이 완전한 등압과정은 아니지만, 이론 계산에서는 무시합니다.
