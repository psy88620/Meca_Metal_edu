모어 원

만든이 : 기계금속 교사 박승엽

한 점의 응력은 어느 방향으로 자른 면을 보느냐에 따라 달라져요. 모어 원은 모든 방향의 응력을 원 하나에 담은 그림이에요. 오른쪽 원 위의 점을 끌면 왼쪽 요소가 회전하고, 수직 응력이 가장 큰 방향(주응력)과 전단 응력이 가장 큰 방향을 찾을 수 있어요.

응력 요소 (회전각 θ)

흐린 사각형은 원래 요소(θ = 0), 진한 사각형이 θ만큼 반시계 방향으로 돌린 요소예요. 화살표 길이가 응력 크기예요.

모어 원

파란 점 X′(σx′, τx′y′)를 끌어 보세요. τ는 아래쪽을 +로 그렸어요(요소와 같은 방향으로 돌게 하는 약속).

계산 결과

-

조건 바꾸기

공식

C = (σx + σy) / 2
R = √(((σx − σy)/2)² + τxy²)
σ1,2 = C ± R, τmax = R
tan 2θp = 2τxy / (σx − σy)
  • 요소를 θ 돌리면 원 위에서는 2θ 돌아요. 그래서 주응력 방향과 최대 전단 방향은 요소에서 45° 차이예요.
  • 주응력 면에서는 전단 응력이 0이에요.
  • 원의 중심 C는 어느 방향으로 돌려도 변하지 않아요: σx′ + σy′ = σx + σy.

그래서 현장에서는

  • 비틀림을 받는 축(순수 전단)은 45° 방향으로 최대 인장이 생겨요. 그래서 분필이나 주철 축은 비틀면 나선 모양(45°)으로 깨져요.
  • 인장 시험에서 연강이 45° 방향 미끄럼선(뤼더스 띠)을 보이는 것은 최대 전단 응력이 45° 면에 생기기 때문이에요.
  • 굽힘과 비틀림을 함께 받는 축은 모어 원으로 주응력과 최대 전단 응력을 구한 뒤 축 지름을 정해요(최대 전단·폰 미세스 기준).
  • 변형률 게이지(로제트)로 세 방향 변형률을 재고 모어 원으로 주응력을 구해요.

생각해 보기

σx = 80, σy = 20, τxy = 40 MPa일 때 주응력은?
C = 50, R = √(30² + 40²) = 50 → σ₁ = 100 MPa, σ₂ = 0 MPa, τmax = 50 MPa예요.
순수 전단 τ = 60 MPa만 있으면 최대 인장 응력과 그 방향은?
C = 0, R = 60이라 σ₁ = 60 MPa, 방향은 45°예요.
단순 인장 σx = 100 MPa에서 최대 전단 응력은?
R = 50이므로 τmax = 50 MPa, 하중과 45° 기운 면에서 생겨요.
